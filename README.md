A token launch radar: it fits an implied value for every protocol that records no token, from the market caps of the protocols whose token already trades, and gives each one a costed farm plan.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
